# CrowdSense

## Enterprise AI-Based Crowd Monitoring and Stampede Prevention System

CrowdSense is an AI-powered crowd monitoring and stampede prevention system designed to improve safety in high-density public environments.

The system combines real-time crowd monitoring, intelligent analysis, and automated alerts to help identify potentially dangerous crowd conditions before they escalate.

## Features

* Real-time crowd monitoring
* Crowd density analysis
* Stampede risk detection
* Automated alerts and notifications
* IoT-based monitoring using ESP8266
* REST API backend
* PostgreSQL database integration
* Modern web dashboard
